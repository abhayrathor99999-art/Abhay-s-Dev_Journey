# Day 5 — Tuples, Sets, Comprehensions, Lambda

## What I Learned
- Tuples: ordered, immutable — comma makes a tuple not parens
- Sets: unordered, unique elements — {} is dict, set() is empty set
- Comprehensions: shorter loops — list, dict, set versions
- Lambda: one-line anonymous function
- Map: apply function to every item
- Filter: keep items matching condition

## Patterns
- Tuple unpacking: name, age, city = person
- Star unpacking: first, *middle, last = numbers
- List comprehension: [x for x in lst if condition]
- Dict comprehension: {k: v for item in lst}

## Mistakes I Made
- Used return inside loop — should be after loop
- Used double quotes inside f-string — use single inside

## One Thing To Remember
- (42) is int. (42,) is tuple. Comma makes it.
