# Day 2 — Control Flow and Loops

## Concepts learned
- if / elif / else — Python stops at first True condition
- Order of conditions matters (FizzBuzz example)
- Comparison operators: >, <, >=, <=, ==, !=
- Logical operators: and, or, not
- Modulo % — remainder, used for even/odd checks
- for loop with range() — when you know how many times
- while True with break — when you don't know how many times
- break vs continue — exit loop vs skip iteration
- Accumulator pattern — num += i
